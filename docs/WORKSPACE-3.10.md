# Creative workspace and reading

SVG Studio provides pen, line, rectangle, ellipse and text tools; select and drag objects or choose them in Layers. Object controls move, duplicate, delete and change stacking order. Imported groups remain groups. Use the source editor for precise coordinates and attributes. Applying code sanitizes active content and external resources. Export uses the applied drawing, not unapplied code.

Stylus pressure changes pen width when available. Finger input pans by default; two fingers zoom. Enable Draw with finger to sketch without a pen. Fit canvas resets navigation. Paper dimensions, stroke, fill and transparent fill are independent controls. Undo/redo and a browser-local draft protect working edits; download backups because clearing browser data removes drafts. This is a browser vector editor, not complete professional illustration-suite parity. Physical Apple Pencil hardware still needs device testing.

The reader offers continuous vertical scrolling for long webcomics, horizontal continuous pages, single pages and spreads. Manga uses right-to-left direction. Gentle motion is separate from layout and remains optional; reduced-motion settings override it. Continuous pages keep the existing lazy rendering instead of pre-rendering animations or adding a heavy page-turn library.

The existing Guide follows the active dialog or workspace. It explains visible controls without triggering them, including converter ranges, separate/joined outputs, streaming, SVG source, objects, pen navigation and comic layouts.

Text-to-PDF uses local script fonts and MuPDF shaping. Regression fixtures cover Persian/Arabic, CJK, Hindi and several other Indic scripts. DOCX/XLSX exports retain Unicode and writing-direction flags. HTML and EPUB use automatic paragraph direction; EPUB language is undetermined instead of incorrectly declaring every document English. Font availability, complex SVG text shaping and Office-layout fidelity still vary. Review exported work in the destination application.

Search Console accepted the sitemap-index resubmission on 17 November 2026. The homepage live test reported it can be indexed. A manual indexing request returned daily quota exceeded. Acceptance and technical eligibility do not mean Google has indexed the site.
