Pocket PDF Workshop is a friendly document toolkit made by Ramtin Neshatvar. Read a PDF, write in the margins, scan a page, or put a paper pile in order—with every document feature free.

Open the PDF workshop ↗Code & contributions

This is the open-source project page. The interactive PWA opens on its own static host; you do not need to rent a server to use it.

✎

A reader with room for ideas.

Search and bookmark pages, highlight passages, type notes, and draw with a mouse, touch, Apple Pencil, or another supported stylus.

▤

A tool for everyday tasks.

Scan, merge, split, rotate, sign, redact, convert, and recognize text. Features stay free; accounts and cloud connections are optional.

⌘

Your files. Your device.

Document processing runs in the browser. Save locally, download a copy, or explicitly choose a cloud transfer. Used tools can be cached offline.

Vibe coded. Open to better ideas.

AI-assisted development, practical tests, clear conversion limits, and an open source tree. Contribute a fix, improve accessibility, report a reproducible bug, or build your own workflow under AGPL-3.0-or-later.
